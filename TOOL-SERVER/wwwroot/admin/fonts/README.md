# Roboto cho Web Admin

Hai subset WOFF2 của Roboto được phục vụ từ chính server, gồm Latin và tiếng Việt. Giữ font variable, không chỉnh sửa binary. Font-display swap; không gọi Google Fonts khi ứng dụng chạy.

Nguồn font: Google Fonts CSS `https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;600;700&display=swap`, tải ngày 2026-10-13 với Chrome User-Agent. Cả bốn weight trỏ về cùng font variable v51.
